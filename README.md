# Afraidofsharks 🦈

Welcome to **Afraidofsharks**! This project is designed to help you navigate and conquer the deep blue waters of Wireshark while keeping those fearsome predators at bay. Engineered Python tools that ingest Wireshark .pcap files and use PyShark to parse and extract protocol‑level details, enabling faster network forensics and detection of suspicious activity. The project automates packet parsing, filtering, and summarization, and exposes a flexible command‑line interface built with argparse so analysts can run reproducible scans, tune filters, and generate actionable insights from captured traffic.

---

## 🚀 Features

- Engineered Python tools to utilize wireshark captured packets providing insight to network activity and spot suspicious behavior.
- Utilized pyshark through Python scripts to parse packet captures and support network analysis. 
- Engineered a  command‑line interface (CLI) with argparse to enable flexible script configuration.
